# ViT：图像块序列上的 Transformer

> [!abstract] 模型定位
> 将图像分块、嵌入为向量序列，经 Transformer 交互得到图像表示。原论文主要研究大规模预训练后的分类迁移，不能只凭架构名称认定任意小数据任务都适用。

## 一、输入输出与流程

图像 → 固定大小图像块 → 共享线性映射 → 位置嵌入和类别 token → 编码器 → 分类表示与预测头。

每块展平维度为 $P^2C$，映射为设定的 $D$ 维嵌入；块数为 $N=HW/P^2$，需满足相应切块条件。

> [!example] 教学计算
> $224\times224$ 图像用 $16\times16$ 块得到 196 个图像 token，再加入一个类别 token。嵌入维度是模型设计参数，不等于 token 数。

## 二、关键机制与学习

自注意力在 token 间交互信息，MLP 变换每个位置的表示；LayerNorm 与残差连接参与每层计算。位置嵌入提供可学习的位置线索，类别 token 最终状态用于整图分类。

预训练后迁移到新类别时，更换分类头并微调相应参数。提高分辨率可能增加序列长度，还需处理位置嵌入的网格变化；不能把任意分辨率当作无成本替换。

## 三、适用条件、自测与证据

本档案描述原论文接口，不覆盖所有 ViT 变体。数据规模、预训练、分辨率和优化影响结果，完整复现需查对应配置；仅有全局信息交互不保证学会全部几何关系。
