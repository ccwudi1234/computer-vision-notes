# ViT：把图像块变为 Transformer 的输入序列

> [!abstract] 核心认识
> ViT 将图像切成固定大小的块，映射为向量序列，加上位置表示后用 Transformer 编码。论文研究大规模预训练后的分类迁移，不等于证明 Transformer 在任意小数据任务上都胜过卷积。

## 一、为什么需要改变输入表示

标准 Transformer 处理向量序列，图像则有二维空间结构。本文选择简洁接口：把每个图像块作为一个序列元素，保留足以供模型学习空间关系的表示，再将分类结果接到序列输出上。

它没有取消学习信号、预训练或图像结构，只是减少了像卷积那样逐层显式写入局部邻接的设计。结构先验少与完全没有先验是两件事。

## 二、从图像到 token 的完整路径

```mermaid
flowchart LR
 I["图像"] --> P["切块与展平"] --> E["线性映射"] --> S["加入类别 token 和位置表示"] --> T["Transformer 编码器"] --> C["类别 token 状态与分类头"]
```

设图像为 $H\times W\times C$，每块为 $P\times P$，可整齐划分时块数：

$$
N=HW/P^2.
$$

每块展平后有 $P^2C$ 个分量，经共享可学习矩阵映射到 $D$ 维。这里“块有多少像素”和“token 有多少维”不是一回事。

> [!example] 教学计算
> $224\times224$ 图像按 $16\times16$ 切块，得到 $14\times14=196$ 个图像块；每个 RGB 块展平为 768 个数，再映射到设定的嵌入维度。加入类别 token 后，序列还有一个额外元素。

## 三、位置、信息交互与类别输出

### 3.1 为什么需要位置表示

线性块映射本身不把序列下标解释成二维位置。原文加入可学习位置嵌入：

$$
z_0=[x_{class};x_p^1E;\cdots;x_p^NE]+E_{pos}.
$$

$E$ 是块映射矩阵，$E_{pos}$ 为序列位置表示，$x_{class}$ 是额外可学习类别 token。位置项加到内容表示上，让后续运算能利用位置；并不保证模型学到任意尺度下都正确的几何关系。

### 3.2 Transformer 块如何逐层更新

原文每个编码层先作 LayerNorm 和多头自注意力，再经残差相加；之后再作 LayerNorm、MLP 和残差相加。注意力负责不同 token 间的信息交互，MLP 对各位置的表示作非线性变换，捷径保留更新前的表示。

类别 token 也参与交互，其最终状态经归一化作为整图表示，再输入分类头。它是一个学习到的信息汇总接口，不是预先写入的类别答案。

## 四、预训练、微调与分辨率

第 3.2 节在大数据上预训练，再将预训练分类头替换为下游分类层进行微调。目标类别变化时，不能沿用原分类头的类别含义。

提高图像分辨率而保持块大小，会增加 token 数；原位置嵌入的网格也需相应处理。作者对位置嵌入作二维插值。这解释了为什么“Transformer 可处理序列”不等于“任何分辨率都无需调整”。

## 五、证据应怎样读

第 4 节将 ResNet、ViT 与混合模型放在不同规模的预训练数据条件下比较，再评价下游迁移。关键问题是数据规模与模型先验怎样相互作用，不能把数据变化带来的效果全归于架构。

本轮已核对第 4.1 节列出的数据与评价设置，未逐表重核所有实验数值，因此不沿用旧稿中脱离具体预训练集、模型规模、分辨率的“最佳精度”。原文主要论证分类表征与迁移，也不能直接认证检测、分割能力。
