# 计算机视觉-学习路线

> [!abstract] 一句话核心
> 先定位问题，再理解机制，最后用练习检验；按先修关系深入。

## 一、三轮学习，深度逐步增加

| 轮次 | 目标 | 产出与验收 |
|---|---|---|
| 第一轮：全景认识 | 覆盖 [[计算机视觉-知识版图]] 八支，知道问题与关系 | 一张自己的知识图；每支能说出输入、输出、一个方法和一个限制 |
| 第二轮：机制基础 | 学习成像、处理、匹配、几何与训练的基础方法 | 能解释核心公式和条件，完成小练习，认识失败情形 |
| 第三轮：专题深入 | 根据兴趣或课程选择方向 | 精读论文、复现基线、做对照实验；医学影像只是可选方向之一 |

第一轮执行 [[计算机视觉-学习任务清单]]。四周是可调整的安排，不代表四周学完整个 CV；不以读完论文数量验收。

## 二、第一轮从哪里开始

1. 阅读知识版图，先给八支各找一个生活中的例子。
2. 用 [[计算机视觉-正向模型与逆问题]] 理解“观测与未知量”，再认识滤波、匹配、深度。
3. 对照 [[目标检测]]、[[图像分割]]，认识分类、框、掩码、关键点、轨迹的输出区别。
4. 阅读 [[深度学习革命-2012至2019]] 和 [[视觉基础模型时代-2020至今]]，把结构、训练信号、任务接口拆开理解。
5. 最后用 [[计算机视觉发展史学习笔记]] 串起条件变化，不能把历史顺序当作知识的先修顺序。

缺系统概览的分支，先从教材相应章节的导言、示意图和小结建立认识，记录不懂的点；不要求立刻创建长笔记或下载整批论文。

## 三、第二轮的先修关系

| 目标 | 建议先修 | 最小练习 |
|---|---|---|
| 滤波与恢复 | 图像数组、卷积、噪声；频域按需补 | 改变模糊核/噪声强度，解释细节与噪声的取舍 |
| 匹配与配准 | 特征、距离、坐标变换、最小二乘和异常值 | 在两张图上区分匹配错误与变换模型错误 |
| 分类与训练 | 向量矩阵、链式法则、概率、损失、梯度下降 | 区分训练误差与验证误差，检查一次数据泄漏风险 |
| 检测与分割 | 表征、分类、坐标/掩码、IoU | 区分漏检、定位错、类别错；比较框和掩码的评价 |
| 深度与三维 | 投影、标定、匹配、几何变换 | 用双目深度与视差关系解释远处深度为何更敏感 |
| 视频 | 图像特征、运动与对应关系 | 区分相机运动和物体运动；区分光流与目标轨迹 |
| 生成与多模态 | 概率、表征、训练目标和迁移评价 | 解释“生成好看”“分类正确”“物理合理”为何不是同一指标 |

不需要把所有数学先学完；遇到卡点就回补对应工具。第三轮再决定工程项目与论文，不把全部方向同时开工。

> [!tip] 选择阅读深度
> 总览用于定位关系，模型档案用于看流程，原文精读用于追推理和证据。术语卡帮助跨过当前卡点，不替代整章理解；按问题选读即可。

## 四、材料怎么用

- 教材负责知识骨架；历史综述负责解释视角；原论文负责关键机制和证据。
- 每个问题先看已有笔记，再回原文；不因模型知名就强制精读。
- 涉及数字时保留数据集、版本与表号；“已入库”“已核数字”“已精读”分别记录。
- 本人学习状态只在任务清单记录；现有历史“已读”不自动继承为个人完成。

## 五、自测与调整

闭卷解释后，再看材料纠错。答不出输入输出就回第一轮，答不出机制或条件就回第二轮，不必从头重复。四周后选择一个分支深入，其余保留在知识地图中。
