# HOG：把局部轮廓变成可比较的数字

> [!abstract] 简明定义
> 方向梯度直方图把图像局部的梯度方向与强度汇总，并在相邻区域归一化，形成描述局部形状的特征。

## 一、直观例子

行人的衣服颜色会变，但头肩、躯干和腿部的轮廓仍有一定规律。HOG 不逐像素记颜色，而记录不同小区域中“变化主要朝哪个方向”。这是形状线索，尚未给出“有人”的判断。

## 二、怎样得到描述子

由水平、竖直方向的图像差分得到梯度，再让像素按梯度幅值向方向区间投票。小单元 cell 记录直方图，相邻 cell 组成 block 做局部归一化；多个重叠 block 的结果拼成窗口描述。局部归一化有助于减轻亮度、对比度变化，但不消除所有光照影响。

原论文在图像金字塔上滑动检测窗口，用 HOG 特征配合线性 SVM 评分，再处理重复检测。**HOG 是描述，SVM 是判别，滑窗与多尺度搜索负责找位置。**

## 三、易混与边界

[[SIFT]]也使用梯度统计，但关键点选择和方向对齐方式不同。HOG 并非天然旋转不变；人横躺与直立时的特征分布会变。[[DPM]]在 HOG 类特征上进一步建模部件及相对位置。
